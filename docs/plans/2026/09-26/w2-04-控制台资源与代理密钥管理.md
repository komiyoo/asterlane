# 控制台资源与代理密钥管理

范围以 [页面范围](../../../architecture/console-separation.md#页面范围) 为准，凭据处理遵循 [认证与敏感数据](../../../architecture/console-separation.md#认证与敏感数据)，既有能力见 [页面地图](../../../admin/admin-console.md#页面地图与-api-缺口)。[^arch] [^console]

## Context

应用外壳已提供认证、API 类型和固定路由。本计划替换资源与代理密钥的占位入口，覆盖旧页面已有的配置和敏感操作，不新增独立 key pool CRUD。

## Approach

先迁移资源列表、创建与删除，再迁移 key CRUD/scope，最后接入一次性签发流程。表单状态留在所属页面，API 调用复用统一入口；不修改后端鉴权或持久化语义。

## Files

- `web/src/features/resources/`、`web/src/features/proxy-keys/` — 本计划拥有的页面与表单。
- `web/src/api/resources.ts`、`web/src/api/proxy-keys.ts` — 类型化业务调用。
- `web/e2e/resources.spec.ts`、`web/e2e/proxy-keys.spec.ts` 及对应组件测试 — 管理写操作与敏感数据生命周期。
- [`src/admin/ui/tabs/resources.js`](../../../../src/admin/ui/tabs/resources.js)、[`src/admin/ui/tabs/keys.js`](../../../../src/admin/ui/tabs/keys.js) — 只作行为对照，切换计划前不删除。

## Reuse

- 统一 API client、生成类型、认证上下文与确认 Dialog — 不另建请求封装或全局 token store。
- `resources.js` 的 auth/key pool 输入语义、`keys.js` 的 scope 与编辑行为 — 保持字段含义和缺省行为。
- `core.js::openTokenDialog` 的一次性展示、过期时间和复制流程 — 改为局部 React 状态，避免全局缓存。
- `src/admin/resource_keys.rs`、`src/admin/tokens.rs` 和 `tests/gateway_auth.rs` — 复用后端测试证据与假凭据构造思路。

## PR1 资源配置

- [x] 实现资源列表、创建、删除，覆盖认证类型、header 名、secret 引用、key pool 策略与引用列表；只读显示不拿脱敏引用当真实值提交。
- [x] 提交前显示必填/基础格式反馈，服务端业务错误常驻显示；失败保留输入，成功刷新列表，重复点击只发出一次写请求。
- [x] 测试 none/bearer/header、非法 secret 输入、池引用和删除取消/确认；真实网关验证创建后的认证类型和池大小显示。

## PR2 代理密钥与 scope

- [x] 迁移 key 创建、编辑、删除，保留 allow/deny、server/tool 选择、分页大小、限额与用量显示；工具不可用时明确提示，不静默清空已有 scope。
- [x] 处理非法页大小、限额和后端正则校验错误；删除显示目标 key，取消不发请求，失败不伪装成功。
- [x] 测试切换编辑对象、过滤工具列表、修改 scope 后的实际工具可见性；验证请求中没有 token_ref/token_digest 等非本表单拥有的字段。

## PR3 签发、轮换与吊销

- [x] 实现过期时间、签发/轮换、复制、关闭与吊销；结果只存弹窗临时状态，关闭/退出清空，签发期间避免意外关闭丢失唯一结果。
- [x] 禁止自动重试与重复提交；网络结果不确定时提供明确反馈，不能在重开弹窗或重新渲染时再签发一次。
- [x] 验证轮换后旧 token 失效、吊销后的界面显示符合后端 legacy 语义；测试保留另一把有效 key，使 gateway 维持 required 模式，避免把开放模式误判为吊销失败。
- [x] 浏览器断言关闭后 DOM、sessionStorage/localStorage 和页面公共状态无签发 token；真实网关验证签发、调用、轮换、吊销和审计，统一使用测试值。

## Verification

运行相关组件测试、`just check` 和 `just web-e2e` 的资源/key 用例。验收同时观察请求次数、最终列表和实际网关授权效果，不能仅以成功提示判断操作完成。

文件归属为 resources/proxy-keys 及其 API/测试。与 MCP 计划可并行；路由入口已经由前置计划注册，共享组件如需变更先协调归属，避免两处建立同名 helper。
